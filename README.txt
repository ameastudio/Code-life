CODE LIFE — ILLUSTRATED BACKGROUND UPDATE

Designed for your existing ameastudio/Code-life GitHub Pages repository.

WHAT THIS CHANGES
- Uses the approved floating-city artwork in the entry and learner-setup screens.
- Adds real illustrated backgrounds for the Code City welcome and HTML/CSS/JavaScript districts.
- Keeps checkpoint numbers and buttons separate from the background so they remain tappable.
- Adds illustrated Playground, lesson, course, progress, arcade and furnished My Pet backgrounds.
- Preserves the existing blue Code Life </> square logo, all six current pets, learning engine, progress and settings.

ONE UPLOAD
1. Unzip this package.
2. Open GitHub > ameastudio > Code-life > Add file > Upload files.
3. Drag ALL the extracted files AND the assets folder into the repository root.
   Keep assets/backgrounds as a folder: do not flatten it.
4. Commit to the existing main branch. Replace index.html and service-worker.js
   and add v5-backgrounds.css, v5-backgrounds.js and assets/backgrounds/*.
5. Wait for GitHub Pages to republish. Refresh Safari; if necessary close and reopen
   the installed PWA so the refreshed service worker picks up the artwork.

IMPORTANT
- Don't delete your other root files (app.js, styles.css, v4.js, v4.css, curriculum.js,
  existing pet PNGs, icons, manifest and so on). This is an overlay, not a new app.
- The approved illustrations are static scenery. The existing cropped pet PNG art and
  future rigged animation are separate work; this update does not claim to fix either.
- Onboarding only appears for a fresh user; your existing local progress will remain.
